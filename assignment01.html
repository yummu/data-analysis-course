4.1研究问题

利用深圳市10个区2021年1月至2026年9月的残疾人两项补贴区-月汇总数据，描述并比较残疾人福利补贴的覆盖规模、领取结构与人均待遇水平这一基层公共服务供给现象，并分析其在各区之间、69个月期间以及不同年龄、性别与残疾类型群体中的差异。

阶段二：完整数据项目

5.1 问题、文献与数据说明

1.本研究围绕”深圳市残疾人两项补贴的覆盖规模、领取结构与人均待遇在地区、时期与群体间呈现怎样的差异”这一公共管理问题展开。两项补贴是国家层面第一项残疾人专项福利制度，事关兜底保障的公平与效率。

2.问题的公共价值。残疾人是需要格外关心的困难群体，补贴资金来源于财政、面向基本民生。厘清补贴在区域间、群体间的分布是否均衡，能够揭示公共资源是否精准惠及最需要的人群，对优化兜底保障、推进共同富裕具有直接的政策含义。

3.相关文献与类似方法。既有研究以深圳市为例，利用两项补贴的行政发放记录与家庭收支调查数据，评估政策的瞄准偏误，发现生活补贴漏保、护理补贴误保较为普遍，并指出类型化瞄准未能充分对应真实照护需求¹。该研究证明，借助深圳本地的两项补贴行政数据，可以刻画补贴的覆盖与结构并支撑公共治理判断；本研究沿用同一城市、同一政策的公开汇总数据，从规模—结构—区际差异三个维度做描述性分析，与之形成方法上的呼应。

4.数据的分析单位、时间与空间范围。数据来自深圳市政府数据开放平台，由深圳市民政局发布。分析单位为”地区—月”面板，一行代表深圳市某一区某一个月的补贴汇总；时间覆盖2021年1月至2026年9月（共69个月），空间覆盖全市10个区，共690行、21个变量。

5.数据为何能支撑该问题。数据包含合计人数、发放资金、护理与生活补贴领取人数、性别与年龄结构、重点保障对象类别等字段，足以直接回答”规模如何变化、结构怎样、区际差异多大”三类描述性问题；且为区级聚合统计，不含个人敏感信息，可公开使用。

6.数据不能回答什么。本数据为区—月汇总，无法识别个体是否应保未保或错保（即瞄准偏误的具体个体机制）；缺少政策调整、人口结构、财政投入等外生变量，不能解释差异的成因，所得结论仅作描述性与探索性判断，不构成政策因果效应。

# 用 stopifnot() 固化核心规则；若报错应查数据

  !anyDuplicated(data[c("地区", "月份")]),
  # 规则2：每个 地区+月份 组合恰好 1 行（去重未丢失）
  all(dplyr::count(data, 地区, 月份)$n == 1),
  # 规则3：核心计数变量非负
  all(data$`合计人数（人）` >= 0, na.rm = TRUE),
  all(data$`发放资金合计（元）` >= 0, na.rm = TRUE),
  # 规则4：派生比率落在 [0,1]
  all(data$护理覆盖率 >= 0 & data$护理覆盖率 <= 1, na.rm = TRUE),
  all(data$生活覆盖率 >= 0 & data$生活覆盖率 <= 1, na.rm = TRUE),
  all(data$同时领取率 >= 0 & data$同时领取率 <= 1, na.rm = TRUE),
  all(data$重度占比   >= 0 & data$重度占比   <= 1, na.rm = TRUE),
  # 规则5：人均月补贴非负

  length(unique(data$月份)) ==
